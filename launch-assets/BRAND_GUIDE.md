# Rta-Smriti Brand Guide

## Core Idea

Rta-Smriti is calm local infrastructure for project memory. It should feel precise, inspectable, private, and quietly advanced.

## Voice

- Plain language before technical detail.
- Confident, never mystical or inflated.
- Evidence-first claims with explicit alpha maturity.
- Prefer “project memory” and “focused context pack” over “AI superbrain.”

## Visual System

| Role | Color |
| --- | --- |
| Graphite background | `#050A10` |
| Raised surface | `#08131D` |
| Primary text | `#EDF7FF` |
| Muted text | `#8DA5B7` |
| Local memory / primary | `#5EEAD4` |
| Files / observation | `#38BDF8` |
| Inference / imports | `#FBBF24` |
| Prior memory | `#A78BFA` |
| Hypothesis | `#F472B6` |

Use cyan and teal for the core system. Amber, violet, and pink are semantic accents, not decoration. Avoid gradients, floating blobs, glossy glass cards, and generic AI imagery.

## Typography

- Product and launch UI: Inter, Segoe UI, or a neutral sans-serif.
- Evidence labels and commands: a readable system monospace.
- Letter spacing remains `0`.

## Image Rules

- Show the real Atlas demo console, not mock interfaces.
- Keep the radial project graph recognizable.
- Never show a real project name, username, absolute path, SQLite brain, context pack, or private thread.
- Use the generated cinematic key art only when the product screen remains inspectable.
