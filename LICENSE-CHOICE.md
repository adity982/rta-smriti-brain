# License Choice Required Before Public Release

No open-source license has been selected yet.

Before publishing on GitHub, choose one:

- MIT: permissive, simple, common for developer tools.
- Apache-2.0: permissive plus explicit patent grant.
- AGPL-3.0: strong copyleft for network/server usage.
- Proprietary/private: keep all rights reserved while validating the product.

Recommended default for a public developer tool: Apache-2.0 or MIT.

Do not publish this repository as open source until the license decision is made and a real `LICENSE` file is added.
