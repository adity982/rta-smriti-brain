# Code of Conduct

Rta-Smriti contributors are expected to be respectful, specific, and constructive.

## Expected

- Discuss ideas and code without attacking people.
- Welcome questions from people with different experience levels.
- Give reproducible, evidence-based feedback.
- Protect private repository data, paths, memories, and credentials.
- Accept maintainer decisions and disagree professionally.

## Not Accepted

Harassment, threats, discrimination, sexualized conduct, deliberate disclosure of private data, sustained disruption, or personal attacks are not accepted in project spaces.

Maintainers may edit or remove contributions and restrict participation when needed to protect the community. Report conduct concerns privately to the repository owner through GitHub. Do not include sensitive project data in a report.
