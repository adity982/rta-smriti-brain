# Roadmap

## Next

- Guided first-run onboarding and cross-platform install validation
- Incremental repository watch mode
- Richer retrieval evaluation corpus and relevance diagnostics
- Optional embeddings behind a local, replaceable provider interface
- More MCP host recipes and community agent adapters

## Later

- Export/import with explicit redaction and provenance
- Multi-repository workspaces
- Pluggable parsers for additional languages
- Signed brain snapshots and stronger integrity checks

Roadmap items are intentions, not commitments. Local-first operation and inspectable evidence remain non-negotiable design constraints.
