# Roadmap

## Current Release Candidate

- Managed console lifecycle and optional owner-controlled login startup
- One-command canonical-root onboarding with watcher and console recovery
- Evidence-aware pre-action governance with provenance and override receipts
- Retrieval diagnostics and bounded dependency, dependent, impact, evidence, and relevance queries
- Privacy-safe public benchmark harness with reproducible quality gates
- Isolated multi-brain workspaces and cross-project retrieval
- Selective redacted export/import with integrity and conflict checks
- Authenticated HMAC-SHA256 local snapshots
- Opt-in managed Git checkpoint hook
- Evidence-aware operator feedback and conservative memory decay

## Next After v0.4.0-alpha

- Expand the public benchmark with community-reviewed corpora and blinded human relevance judgments
- Add approximate nearest-neighbor indexes for very large local embedding collections
- Publish more native LSP recipes and richer Tree-sitter call queries
- Add workspace-level context-pack composition with explicit per-project budgets
- Add public-key snapshot signatures and optional encrypted portable archives
- Add more MCP host recipes and community agent adapters

Roadmap items are intentions, not commitments. Local-first operation and inspectable evidence remain non-negotiable design constraints.
