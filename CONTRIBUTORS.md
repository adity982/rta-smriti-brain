# Contributors And Build Provenance

[Sulabh Dubey](https://github.com/sulabhdubey).

The product was built with [OpenAI Codex](https://openai.com/codex/) as the
primary AI agent for architecture exploration, implementation, testing,
security review, documentation, and release preparation. Sulabh supplied the
product vision, research direction, operating requirements, evaluation
judgment, privacy boundaries, and final approval for changes and publication.
